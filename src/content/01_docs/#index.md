StaticSearch is a search engine you can add to any static website. It uses client-side JavaScript and JSON data files so there is no need for back-end server technologies or a database.

Try it by using the **search icon** at the top of the page, pressing <kbd>Ctrl</kbd> + <kbd>K</kbd>, or clicking this <a href="#" data-static-search="search" class="button">SEARCH</a> button.

StaticSearch:

* works with any static site. You can use [Publican](https://publican.dev/) or any other static website generator.

* supports 27 languages but most Latin-based text will work.

* builds word indexes from your generated HTML pages. There's no need to mark content or programmatically add content.

* can add search functionality with a single `<script>` tag but offers other fully-customizable options.
